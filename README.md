# 在线加密聊天网站

一个轻量的在线端到端加密聊天网站。服务端只负责静态页面、SSE 长连接和密文转发，不保存聊天记录，不接触明文。

## 运行

```powershell
cd C:\Users\Administrator\Desktop\在线加密聊天网站
npm.cmd start
```

浏览器打开：

```text
http://localhost:3000
```

同一房间最多 2 人。双方输入相同房间号、相同会话口令后进入；密钥建立后需要核对页面显示的安全码。

## 安全设计

- 消息加密在浏览器端完成，服务端只转发 `hello` 和 `chat` 信令。
- 密钥协商使用 Web Crypto：ECDH P-256 + PBKDF2-SHA-256 + HKDF-SHA-256 + AES-256-GCM。
- 会话口令不发送给服务器，会混入最终会话密钥。
- 每条消息使用独立 96-bit 随机 nonce，并使用 AES-GCM 附加认证数据绑定房间、发送方、消息 ID 和时间。
- 服务端无数据库、无聊天记录持久化；房间和连接只存在内存中。

## 必须注意

任何软件都不能承诺“绝对无漏洞”。这个项目使用浏览器标准密码学 API，避免自写底层加密算法，但上线前仍应做代码审计、依赖和服务器配置审查。

手机或外网访问时必须使用 HTTPS。`localhost` 可以直接使用 Web Crypto；如果用手机访问局域网 IP，建议放到 Caddy、Nginx、Cloudflare Tunnel 或其他 HTTPS 反向代理后面。

## 部署建议

- Node.js 18 或更高版本。
- 服务器 1 核 512MB 内存即可跑小规模会话。
- 生产环境使用 HTTPS 反向代理。
- 如果要支持多人群聊、历史消息、多设备登录，需要重新设计群组密钥和身份认证模型。
